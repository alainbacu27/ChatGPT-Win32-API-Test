# ChatGPT-Win32-API-TEST

A series of Win32 binaries just for testing, generated by AI Assistants like ChatGPT.

You can compile these binaries not only with Visual Studio, using GCC/MinGW or other compilers for Windows, but primarily works with Visual Studio (2022 or 2026, and maybe future versions of Visual Studio)


# Compiling Binaries with Visual Studio

To compile CombaseExample.cpp, run this command:

cl /nologo /EHsc /std:c++17 /W4 CombaseExample.cpp /link /OUT:CombaseExample.exe

To compile RoGetApartmentIdentifier.exe, run this command:

cl /nologo /std:c++17 /EHsc /W4 /permissive- RoGetApartmentIdentifier.cpp /Fe:RoGetApartmentIdentifier.exe
